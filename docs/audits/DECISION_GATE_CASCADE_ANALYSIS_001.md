## 2. Conditional Cascade (Delta Failures Overlap)

To determine if `delta_extreme` is a primary bottleneck or an overlapping filter, we analyzed the **80,165 candidates** blocked by this gate:

* **Total Delta Extreme Blocks**: 80,165  
* **Also failed Confidence Floor**: 46,836 (**58.42%**)  
* **Also failed EV Threshold**: 51,199 (**63.87%**)  
* **Also failed Position Sizing Floor ($0.10)**: 80,153 (**99.99%**)  
* **Passes all other gates (Clean Veto)**: **11 candidates** (0.01%)  

### Conclusion
Disabling the `delta_extreme` gate would have only allowed **11 trades** to execute across the entire month. The remaining 99.99% of candidates would have been blocked by the sizing or confidence gates downstream. This proves that `delta_extreme` is not the bottleneck; rather, it is a highly overlapping safety gate that triggers early.
