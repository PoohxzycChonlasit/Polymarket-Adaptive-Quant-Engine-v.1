# RUNTIME STORAGE MANUAL CLEANUP PLAN (RUNTIME_STORAGE_MANUAL_CLEANUP_PLAN_001)

This plan details a safe, batch-by-batch manual cleanup approach for repository storage space, targeting redundant scratch files, compression of rolling logs, and pruning of old snapshots.

---

## 1. Safety Rules & Shields
Before executing any cleanup commands, the operator must verify that the following safety boundaries are maintained:
1. **Never Touch Current Day:** File name `2026-06-22` or files modified on the current day must never be deleted or compressed.
2. **Never Touch Trade Journal:** The folder `runtime/quant_data/trade_journal/` is a critical source of truth and must remain untouched.
3. **Never Touch Snapshots:** The folder `runtime/quant_data/reports/phase_b_daily_snapshots/` contains historical reports and must remain untouched.
4. **Never Touch Source Code:** No Python code (`*.py`), configuration files (`.env`, `config/`), or ownership files (`runtime/ownership/`) may be deleted or modified.
5. **Rollback Recycler:** Prior to deletion, any file is held in a temporary recycler directory or local backup folder (`runtime/backup_untracked/`) for 48 hours to allow instant recovery if needed.

---

## 2. Batch 1: Scratch and Validation Roots Deletion

### Details
- **Description:** Deletes old, rebuildable validation root runs and temporary duplicate logs inside the `scratch/` folder.
- **File Count:** 38 files
- **Space Reclaimed:** **`11.46 GB (12,308,829,380 bytes)`**
- **Risk Level:** **VERY LOW** (Scratch folder contains transient developer/validator runs only; no operational runtime files are affected).
- **Rollback Possibility:** **HIGH** (If needed, files can be re-generated by running the offline validator engine).

### Target Paths
1. `scratch\decision_log_slim_index_bounded_source\decision_log\2026-05-10.jsonl` (1.03 MB)
2. `scratch\decision_log_validation_root\*.jsonl` (37 files matching dates from `2026-05-08` to `2026-06-15`)

### Commands to Run (PowerShell)
```powershell
# Create backup directory just in case
New-Item -ItemType Directory -Path "runtime\backup_untracked\batch_1" -Force

# Backup targeted scratch files to local recycler
Copy-Item -Path "scratch\decision_log_slim_index_bounded_source\decision_log\2026-05-10.jsonl" -Destination "runtime\backup_untracked\batch_1" -Force
Get-ChildItem -Path "scratch\decision_log_validation_root\*.jsonl" | Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-7) } | Copy-Item -Destination "runtime\backup_untracked\batch_1" -Force

# Execute safe deletion
Remove-Item -Path "scratch\decision_log_slim_index_bounded_source\decision_log\2026-05-10.jsonl" -Force
Get-ChildItem -Path "scratch\decision_log_validation_root\*.jsonl" | Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-7) } | Remove-Item -Force
```

## 3. Batch 2: Compress Old Logs (Aged > 7 Days)

### Details
- **Description:** Compresses verbose JSONL files in `decision_log`, `research_log`, and `risk_log` older than 7 days using gzip.
- **File Count:** 103 files
- **Initial Footprint:** **`19.66 GB (21,108,091,739 bytes)`**
- **Estimated Reclaimed:** **`17.69 GB`** (Assuming 90% gzip compression ratio)
- **Risk Level:** **LOW** (Files are preserved on disk in compressed form; runtime only writes to the current day file).
- **Rollback Possibility:** **VERY HIGH** (Files can be decompressed instantly back to flat JSONL using standard gunzip utilities).

### Target Paths
- `runtime\quant_data\decision_log\*.jsonl` (older than 7 days, date `<= 2026-06-14`)
- `runtime\quant_data\research_log\*.jsonl` (older than 7 days, date `<= 2026-06-14`)
- `runtime\quant_data\risk_log\*.jsonl` (older than 7 days, date `<= 2026-06-14`)

### Commands to Run (PowerShell via Python)
Run this command from the repository root to compress files matching age criteria:
```powershell
python -c "import gzip, shutil, os, glob; [gzip.open(f+'.gz', 'wb').writelines(open(f, 'rb')) or os.remove(f) for f in glob.glob('runtime/quant_data/decision_log/*.jsonl') + glob.glob('runtime/quant_data/research_log/*.jsonl') + glob.glob('runtime/quant_data/risk_log/*.jsonl') if os.path.basename(f) <= '2026-06-14.jsonl']"
```

## 4. Batch 3: Delete Old Market Snapshots (Aged > 3 Days)

### Details
- **Description:** Prunes dense bids/asks CLOB snapshots that are older than 3 days (date `<= 2026-06-18`).
- **File Count:** 40 files
- **Space Reclaimed:** **`3.96 GB (4,255,938,064 bytes)`**
- **Risk Level:** **MEDIUM-LOW** (Market snapshots are temporary derived data. We confirm they are not the source of truth for trades).
- **Rollback Possibility:** **NONE** (Permanent prune. Cannot be easily rebuilt unless raw websocket feeds are replayed).

### Target Paths
- `runtime\quant_data\market_snapshots\*.jsonl` (older than 3 days, date `<= 2026-06-18`)

### Commands to Run (PowerShell)
```powershell
# Backup to recycler first
New-Item -ItemType Directory -Path "runtime\backup_untracked\batch_3" -Force
Get-ChildItem -Path "runtime\quant_data\market_snapshots\*.jsonl" | Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-3) } | Copy-Item -Destination "runtime\backup_untracked\batch_3" -Force

# Execute safe deletion
Get-ChildItem -Path "runtime\quant_data\market_snapshots\*.jsonl" | Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-3) } | Remove-Item -Force
```
