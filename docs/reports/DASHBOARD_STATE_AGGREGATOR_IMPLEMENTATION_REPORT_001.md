## Behavior Implemented

- Missing `bot_status.json` produces `meta.partial=true` and a `BOT_STATUS_MISSING` alert.
- `bot_status.json` maps runtime, safety, portfolio, and signals.
- Owner file maps status, PID, run ID, heartbeat count, and heartbeat timestamp.
- Trade journal aggregates open/close counts, closed trade count, win/loss/breakeven, win rate, realized PnL, attribution completeness, and recent trades.
- Decision log aggregates decision count, skip reasons, asset counts, signal-name counts, and recent decisions.
- Risk log maps latest risk mode, available risk budget, exposure, risk event count, and recent risk events.
- System health maps latency, disabled writers, reconciliation state, and Telegram/heartbeat alert counters.
- Storage maps runtime/quant-data sizes, per-category counts, and compression dry-run manifest fields.
- Reports map edge inventory, replay, and no-entry summaries when available.
- Research exports map canonical regime metadata when available.
- Output write is atomic through `.tmp` then replace.
