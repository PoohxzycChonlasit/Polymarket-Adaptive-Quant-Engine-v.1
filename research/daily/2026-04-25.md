## กลุ่มที่ 1 — Strategy Tuning

### เพิ่ม flags ใหม่ใน main.py + backtester_5m.py

**`--balance <USD>`** — ตั้ง starting balance ได้ (default $8.89)

**`--score-scale`** — bet size scales กับ signal score:
```
scale = min(1.0 + (signal_score - 0.50) × 2.2222, 2.0)
score=0.95 → 2.0× | score=0.85 → 1.5× | score=0.50 → 1.0×
```

**`--momentum-price`** — entry price discount เมื่อ momentum แรง:
```
discount = min(|momentum_pct| × 0.10, 0.16)
entry = max(0.50 - discount, 0.32)
```
จำลองการซื้อ counter-side ที่ราคา discount (เหมือน trader "Unlawful-Shear" ที่ entry ที่ 0.30–0.40 ไม่ใช่ 0.50)

**Multi-asset** — `--asset BTC,ETH` แบ่ง balance เท่าๆ กันแล้ว run แยก

### ปรับ bankroll tiers (aggressive)
| Tier | เดิม | ใหม่ |
|------|------|------|
| small | 0.75% | 1.0% |
| conservative | 1.0% | 1.5% |
| balanced | 1.25% | 2.0% |
| growth | 1.5% | 2.5% |

### ผลลัพธ์ backtest 60d (full combo: BTC+ETH + --score-scale + --momentum-price)
```
Sharpe: 2.927 ✅ (vs baseline 1.18)
WR: 55.9%
MaxDD: 15.2% ✅
ผ่าน gate ทุกตัว
```

### ข้อสรุปจาก experiment
- Multi-asset (BTC+ETH) ดีกว่า single-asset เสมอ — variance ลดลง
- `--score-scale` + `--momentum-price` ร่วมกันให้ Sharpe สูงสุด
- Score filter ≥ 0.75 ช่วย single-asset (losing days 33%→27%) แต่ทำร้าย multi-asset (24%→29%) — อย่าใช้ filter กับ multi-asset
