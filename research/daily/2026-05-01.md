### 7. Paper smoke run

รัน short paper test สำเร็จ:

```bash
python hft_paper_run.py --duration-minutes 0.05 --loop-sec 1
```

ผล smoke:

- เปิด 5 paper positions
- ทั้งหมดเป็น NO
- ปิดด้วย SL ก่อนหมด window
- PnL รวม `-$3.1515`
- summary เขียนที่ `runtime/hft_summary_latest.md`

หมายเหตุ: smoke สั้นมาก ใช้ตรวจ runtime ไม่ใช่ performance validation

### 8. Duration stop guard

หลัง smoke พบว่าเมื่อ duration ถึงแล้ว ระบบยังเปิดไม้เพิ่มระหว่างรอ position เดิม settle

แก้แล้ว:

- เมื่อถึง duration จะไม่เปิด position ใหม่
- ถ้ามี position เปิดอยู่ จะรอ TP/SL/settlement เท่านั้น
- smoke ซ้ำด้วย `--duration-minutes 0.001` ผ่าน: ไม่มี new entry หลัง stop
