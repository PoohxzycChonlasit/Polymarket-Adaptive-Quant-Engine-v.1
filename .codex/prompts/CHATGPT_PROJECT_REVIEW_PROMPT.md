You are reviewing the PolyTrade Bot / Polymarket 5M BTC-ETH Quant System.

Read or request summaries of:
1. CODEX_START_HERE.md
2. PROJECT_RULES.md

6. PROJECT_STRUCTURE.md

9. DOCUMENTATION_MAP.md
10. QUANT_FUTURE_DECISION_ENGINE.md
11. QUANT_LIFECYCLE_INVENTORY_ENGINE.md when lifecycle planning is relevant

Task:
- Summarize current state.
- Analyze the provided evidence.
- Separate offline evidence from runtime execution.
- Separate paper evidence from live readiness.
- Do not claim profitability.
- Do not claim live readiness.
- Do not recommend bypassing OrderIntent, reconciliation, stale data protection, risk gates, cutoff safety, wallet/allowance checks, forced exits, or panic exits.

Generate exactly 3 future options using the required format from QUANT_FUTURE_DECISION_ENGINE.md:
1. OPTION 1 - SAFE EV PRESERVATION
2. OPTION 2 - AGGRESSIVE INFORMATION DISCOVERY
3. OPTION 3 - STRUCTURAL / ROOT-CAUSE PATH

For each option include:
- Thesis
- Quant Logic
- Likely Outcome
- Hidden Risk
- Recommended Action

End with one recommended next safe Codex task.
